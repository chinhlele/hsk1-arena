# Đấu Trường HSK1

Game tự học HSK 1 theo chuẩn HSK 3.0 (300 từ), chạy hoàn toàn trên trình duyệt.

- Lộ trình 22 chặng theo chủ đề: học thẻ rồi luyện ngay
- Đoán nghĩa, tìm chữ Hán, nghe chọn từ, thanh điệu, xếp câu, ngữ pháp, số và thời gian
- 60 bộ thủ thường dùng, có so sánh các cặp dễ nhầm
- Bật/tắt pinyin và màu thanh điệu trên chữ Hán

Mở `index.html` hoặc truy cập bản GitHub Pages của repo. Tiến độ học lưu trong trình duyệt của từng máy.
